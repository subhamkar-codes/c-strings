# C Strings

Programs covering strings in C — from basics to built-in string functions.

## Files

| File | Concept |
|---|---|
| `01_strings.c` | String basics — declaration and initialization |
| `02_printing_string.c` | Different ways to print a string |
| `03_input_in_string.c` | Taking string input from user |
| `04_gets.c` | Using `gets()` for input with spaces |
| `05_strings_function.c` | Introduction to string handling functions |
| `06_stcrpy_strings.c` | `strcpy()` — copying one string into another |
| `07_strcat_string.c` | `strcat()` — concatenating two strings |
| `08_strcmp.c` | `strcmp()` — comparing two strings |

## Concepts covered
- String declaration and initialization
- Character arrays vs strings
- Input methods: `scanf`, `gets()`
- Built-in string functions: `strcpy`, `strcat`, `strcmp`
